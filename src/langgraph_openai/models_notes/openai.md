# langchain_openai exports

| Name | Description |
| --- | --- |
| ChatOpenAI | Interface to OpenAI's chat model APIs. |
| AzureChatOpenAI | Azure OpenAI chat model integration. |
| AzureOpenAI | Azure-specific OpenAI completion (LLM) integration. |
| OpenAI | OpenAI completion (LLM) model integration. |
| OpenAIDecisions | Asks typed questions (predicates, choices, scores) over text/images via the OpenAI Decisions API. |
| OpenAIEmbeddings | OpenAI embedding model integration. |
| AzureOpenAIEmbeddings | Azure OpenAI embedding model integration. |
| StreamChunkTimeoutError | Raised when no streaming chunk arrives within `stream_chunk_timeout`. |
| custom_tool | Decorator to create an OpenAI custom tool with freeform string input. |
